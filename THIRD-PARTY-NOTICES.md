# Third-party material and provenance

## Publication status

The owner stated on 2026-11-05 that no public redistribution permissions or
license conditions were available to report for the bundled images and music.
The current packages are therefore local review drafts, not media-cleared releases.
Attribution below records provenance; it is not presented as permission.

## Item artwork and Windows icon

The editor includes 131 item pictures obtained from Super Mario Wiki, hosted
on mario.wiki.gallery. Per-file subjects, URLs and SHA-256 hashes are preserved
in Source/Mk8Editor.App/Assets/sources.json in the source archive.

Reference page: https://www.mariowiki.com/Mario_Kart_8_Deluxe_in-game_statistics

The Windows icon uses the selected PTDV_13.png Metal Mario portrait, converted
to a multi-resolution ICO. The executable embeds both item artwork and the icon.
Removing loose PNG files from a package does not remove embedded artwork.

Mario Kart, characters, vehicles, images and associated trademarks belong to
their respective owners, including Nintendo. This is an unofficial project,
not affiliated with or endorsed by Nintendo.

No game binary, private project or reference spreadsheet is distributed.

No Microsoft runtime installer or NuGet package is bundled.
